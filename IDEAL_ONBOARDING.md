# Zapier Connector — идеальный первый запуск

Источник: `ONBOARDING_FIRST_LAUNCH_STANDARD.md`. Целевой пользователь: small business
owner/ops-специалист на Zapier (самый популярный no-code коннектор).

## 1. Credential type
ОСОБЫЙ класс, аналогично Keragon: не привычный `connect_*` с ключом, а webhook-мост
(исходящий "Catch Hook" URL + входящий webhook с секретом) — Zapier сам инициирует
подключение через "Zap", не через ввод API-ключа в нашем приложении.

## 2. Идеальный флоу
1. **Первое открытие** — `Empty` с явным объяснением ДВУХ направлений (аналогично
   Keragon): "Отправлять события в Zapier" и "Получать события из Zapier" — карточками.
2. **Исходящее** — форма "Вставьте Catch Hook URL из вашего Zap" + Button("Сохранить").
3. **Входящее** — сразу видимый наш webhook URL для копирования в Zap-триггер, с
   секретом для подписи.
4. **После настройки** — журнал последних отправленных/полученных событий видно сразу.
5. **Тестовая отправка** — кнопка "Отправить тестовое событие" сразу после сохранения
   исходящего webhook.
